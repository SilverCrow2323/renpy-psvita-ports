# Changelog

All notable changes to the Ren'Py Vita Hub documentation and catalogue are recorded here.

## [2.0.0] - 2026-11-24

### Added
- Unified the four Sakura Succubus Vita entries under one series guide.
- Added per-title documentation for installation paths, original-game sources, known issues and verification.
- Added shared compatibility, port-status, suggestion, testing and repository-structure guides.
- Added a clear distinction between catalogue entries, proposed candidates, historical conversion failures and separately maintained ports.

### Changed
- Rebuilt the root README as the central Ren'Py Vita catalogue.
- Standardized project language, navigation, status labels and documentation layout.
- Clarified that the repository does not distribute original commercial game data or guarantee compatibility.

### Retained
- Existing issue history and standalone Sakura project repositories for traceability during consolidation review.
- Existing wiki-source documentation and publishing workflow pending a dedicated migration of the GitHub Wiki pages.

### Not included
- No VPK, commercial game data, proprietary assets or binary payloads were copied.
- No source repository was deleted or archived.
- No release tag or binary release was published.
