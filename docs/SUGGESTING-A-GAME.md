# Suggesting a game

Have a Ren'Py title you'd love to see on Vita? Open one issue for one game. It keeps the queue searchable and lets compatibility evidence accumulate in one place.

## Before opening an issue

- Search the [existing issue tracker](https://github.com/SilverCrow2323/Renpy-Vita-Portings/issues).
- Prefer an official store or developer page as the source.
- Check whether the game relies on video playback.
- If known, identify the Ren'Py version and exact game release.
- Do not upload the game itself, extracted assets, scripts, music or other copyrighted files.

## Include

1. Exact title and official source URL.
2. Exact version/build or store release.
3. Ren'Py version, if known.
4. Known video playback, custom rendering, native modules or unusual features.
5. Why you think it may be a reasonable Vita candidate.
6. Existing Vita tests or related ports, if any.

## What happens next?

A suggestion is not an acceptance, a work commitment or a compatibility promise. A maintainer may ask for more information, mark the title as queued, or explain why a known limitation is likely to block a basic conversion.

Please keep one game per issue, even when several titles belong to the same series. A bundle may be used when the games are inseparable for the requested test, but list every title clearly.
