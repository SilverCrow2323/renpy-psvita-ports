# Harvest December: Reharvested! Portable

**Status: In progress**

Repository: [Harvest-December-Reharvested-Portable](https://github.com/SilverCrow2323/Harvest-December-Reharvested-Portable)

This is a Ren'Py port of Harvest December: Reharvested, based on the upstream PC rework by Autumn Rivers and the portable project maintained with takoyaki99. The repository README explicitly describes the Vita port as in progress, with a Switch target planned afterwards.

## Sources

- Original game / rework information: https://natirivers.itch.io/harvest-december-remake
- Upstream portable project: https://github.com/takoyaki99/Harvest-December-Reharvested-Portable

## Installation status

The current repository README does not yet establish a final Vita title ID, VPK release, or game-data destination. Do not infer an installation path from other Ren'Py ports. The catalogue will be updated when the project publishes those details.
