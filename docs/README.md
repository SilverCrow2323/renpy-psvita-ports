## Documentation rules

- Shared project documentation is written in English.
- Mark unknowns as unknown; do not turn missing evidence into a compatibility claim.
- Keep per-game paths, title IDs and known issues on that game's page.
- Link to official game sources where possible.
- Never store or redistribute commercial game payloads here.
