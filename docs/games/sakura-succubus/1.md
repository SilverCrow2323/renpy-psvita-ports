# Sakura Succubus — Vita

**Series entry:** 01  
**Original game:** [Sakura Succubus — Steam app 1202310](https://store.steampowered.com/app/1202310/Sakura_Succubus/)  
**Legacy port repository:** [Sakura-Succubus-Vita](https://github.com/SilverCrow2323/Sakura-Succubus-Vita)  
**Application directory:** ux0:/app/RNPYSS001/

## Install

1. Install the matching Vita port package using the [series installation guide](README.md#shared-installation-workflow).
2. Obtain the original PC game from its official source.
3. Copy that game's game directory to:

```text
ux0:/app/RNPYSS001/game/
```

4. Keep the directory name game unchanged and launch from LiveArea.

The legacy README describes extracting the VPK as an archive and using VitaShell → **TRIANGLE** → **More** → **Install folder** as a quicker alternative to direct VPK installation.
