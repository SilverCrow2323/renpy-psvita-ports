# Sakura Succubus 3 — Vita

**Series entry:** 03  
**Original game:** [Sakura Succubus 3 — Steam app 1406020](https://store.steampowered.com/app/1406020/Sakura_Succubus_3/)  
**Legacy port repository:** [Sakura-Succubus-3-Vita](https://github.com/SilverCrow2323/Sakura-Succubus-3-Vita)  
**Application directory:** ux0:/app/RNPYSSIII/

## Install

1. Install the matching Vita port package using the [series installation guide](README.md#shared-installation-workflow).
2. Obtain the original PC game from its official source.
3. Copy that game's game directory to:

```text
ux0:/app/RNPYSSIII/game/
```

4. Keep the directory name game unchanged and launch from LiveArea.

## Known issue reported by the legacy project

The legacy README reports that **Settings** and **Load/Save** menus can sometimes behave glitchily. It reports that **Quick Load/Save** works without issues.

This is a historical report, not a newly reproduced result. If it occurs, use Quick Load/Save as a workaround and capture the exact menu/action when reporting it.
