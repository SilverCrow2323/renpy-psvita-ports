# Sakura Succubus 4 — Vita

**Series entry:** 04  
**Original game:** [Sakura Succubus 4 — Steam app 1466690](https://store.steampowered.com/app/1466690/Sakura_Succubus_4/)  
**Legacy port repository:** [Sakura-Succubus-4-Vita](https://github.com/SilverCrow2323/Sakura-Succubus-4-Vita)  
**Application directory:** ux0:/app/RNPYSS004/

## Install

1. Install the matching Vita port package using the [series installation guide](README.md#shared-installation-workflow).
2. Obtain the original PC game from its official source.
3. Copy that game's game directory to:

```text
ux0:/app/RNPYSS004/game/
```

4. Keep the directory name game unchanged and launch from LiveArea.

## Known issue reported by the legacy project

The legacy README reports occasional glitches in **Settings** and **Load/Save** menus. It reports that **Quick Load/Save** works without issues.

This is a historical report, not a newly reproduced result. If it occurs, use Quick Load/Save as a workaround and record the exact reproduction steps.
