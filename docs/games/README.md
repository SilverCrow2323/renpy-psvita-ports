# Game sheets

Each title in the catalogue has an individual page generated from a reviewed community proposal. The page records source links, cover artwork when supplied by a public source, known technical clues, current evidence and unresolved questions.

A title remains **Suggested · not evaluated** until an actual test report identifies the exact game build, Vita model and runtime version. Historical issue labels are not treated as current test evidence.

To add a title:
1. Open one issue using the game proposal template.
2. Check for duplicates and confirm the official source.
3. Create a page under `docs/_games/` using the fields shown in [the page template](../GAME-SHEET-TEMPLATE.md).
4. Link the issue and preserve unknown fields as unknown.

Do not upload game data or artwork without permission. Prefer official store cover URLs or assets explicitly licensed for redistribution.
